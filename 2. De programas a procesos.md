
Un programa es estático porque es una serie de instrucciones predefinidas sin estado almacenadas en disco. Un proceso es dinámico porque es la instancia en la que se ejecutan esas instrucciones y evoluciona su estado con el tiempo (PC, registros, recursos)

## Glosario

- Programa fuente: código de alto nivel con direcciones de memoria simbólicas a las que se hace referencia mediante aliases de las variables. Migrable entre entornos y sistemas operativos.
- Compilación: traducción del código fuente a lenguaje máquina para permitir que una computadora ejecute un programa
- Programa objeto: código máquina resultante de compilar un código fuente. Puede tener direcciones relativas al origen o direcciones de memoria reales dependiendo de la compilación (ej: com y exe) y el sistema operativo. Se puede migrar mientras sea entre mismas arquitecturas y mismos S.O. No tiene resueltas las syscalls.
- Programa ejecutable: resultado de haber compilado y link-editado un código fuente. Tiene sus direcciones relativas al origen o reales y sólo es migrable a la misma versión de S.O. y de kernel
- Link-editor: programa que toma uno o más archivos de objeto generados por un compilador y los combina para crear un único archivo ejecutable, biblioteca o módulo de carga. Es parte del toolchain de compilación.
- Loader: componente/mecanismo/software/porción de código/programa auxiliar del sistema operativo encargado de cargar un programa ejecutable desde el almacenamiento a la memoria RAM y dejarlo listo para ejecutarse.
- Programa: conjunto ordenado de instrucciones que pretende resolver un problema.
- Instrucción: unidad de ejecución que dura un tiempo finito y se ejecuta sobre un procesador (atómico, no se puede interrumpir)
- Proceso: 
	- Es una instancia de un programa cargado en Memoria Central al cual se le asocia un contexto de ejecución (Run Time Environment) mediante un vector de estado o Bloque de Control del Proceso (PCB)
	- Consiste en una secuencia de acciones llevadas a cabo a través de la ejecución de una serie de instrucciones para proveer alguna función del sistema.
	- Tiene direcciones reales/relativas al origen y los syscalls resueltos.
## Flujo

- Se compila un programa fuente (código de alto/bajo nivel con direcciones simbólicas) para transformarlo a un programa objeto (código máquina con direcciones relativas)
- El Link-editor se encarga de resolver las syscalls en las direcciones de memoria donde las guarda el sistema operativo
- El loader carga el programa en memoria:
	- Copia el código y los datos desde el disco
	- Reserva memoria y espacios de dirección para código, datos, stack, heap
	- Resuelve detalles finales como bibliotecas dinámicas
	- Transfiere el control al programa (a su función main)
